# روزنو — پلنر عادت‌ها و روتین روزانه

یک وب‌اپ فارسی، راست‌چین و واکنش‌گرا برای پیگیری عادت‌ها و برنامه‌ی روزانه. این پروژه استاتیک است و روی GitHub Pages اجرا می‌شود؛ به سرور یا دیتابیس نیاز ندارد.

## قابلیت‌ها
- روتین‌های پیش‌فرض: بیدار شدن ساعت ۰۷:۳۰، مسواک صبح، صبحانه، مطالعه ساعت ۲۲:۰۰ و خواب ساعت ۲۳:۰۰
- افزودن، ویرایش و بایگانی عادت‌ها با زمان، دسته‌بندی و ایموجی دلخواه
- ثبت وضعیت عادت‌ها به تفکیک روز
- درصد پیشرفت روزانه و میانگین تکمیل ماهانه
- گزارش هر عادت، تشخیص عادت‌هایی با درصد تکمیل پایین، پیشنهادهای کاربردی و تقویم عملکرد ماهانه
- یادداشت روزانه و شمارش روزهای استمرار
- ذخیره‌سازی خودکار با `localStorage`
- خروجی JSON و بازیابی نسخه‌ی پشتیبان
- رابط کاربری واکنش‌گرا برای موبایل و دسکتاپ

## انتشار روی GitHub Pages
1. محتویات این پوشه (`index.html`, `style.css`, `app.js`, `README.md`) را در ریشه‌ی یک repository قرار بده.
2. در GitHub وارد **Settings → Pages** شو.
3. در بخش **Build and deployment** گزینه‌ی **Deploy from a branch** را انتخاب کن.
4. شاخه‌ی `main` و پوشه‌ی `/(root)` را انتخاب و ذخیره کن.
5. پس از اتمام انتشار، لینک GitHub Pages مخزن را باز کن.

## ذخیره‌سازی و حریم خصوصی
اطلاعات در `localStorage` همان مرورگر و همان مبدأ (دامنه) ذخیره می‌شود و به این پروژه هیچ سروری ارسال نمی‌شود. بستن تب یا خاموش کردن دستگاه نباید اطلاعات را پاک کند، اما پاک‌کردن داده‌های سایت/مرورگر، استفاده از حالت خصوصی، تغییر مرورگر یا تغییر دامنه ممکن است به از دست رفتن یا در دسترس نبودن داده‌ها منجر شود. مرتب از **خروجی و نسخه پشتیبان** استفاده کن و فایل JSON را خارج از مرورگر نگه دار.
